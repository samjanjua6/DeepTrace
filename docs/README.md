# DeepTrace Documentation Repository

This directory contains specifications, architectural documents, and academic deliverables for the DeepTrace project.

## Directory Structure

* **`DeepTrace_Project_Documentation.pdf`**: Comprehensive architecture and system specification for mentors and reviewers. *(Note: The actively served public version is located in `frontend/public/DeepTrace_Project_Documentation.pdf` for Caddy and EC2 deployment)*.
* **`DeepTrace_Project_Documentation.html`**: Static HTML reference export of the project documentation.
* **`deeptrace_proposal.html`**: Static HTML project proposal overview.
* **`DeepTrace_Mobile_Viewer_Specification.pdf`**: Architectural specification and wireframe layout for the mobile document viewer module.
* **`academic/`**: Final Year Project (FYP) academic deliverables (LaTeX source, compiled proposal, university logo).
