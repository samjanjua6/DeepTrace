# Academic Deliverables: Final Year Project (FYP)

This directory contains the academic Final Year Project proposal source and compiled documents for the Department of Computer Science, University of Gujrat.

## Files

* **`DeepTrace_FYP_Proposal.tex`**: LaTeX source code for the FYP project proposal.
* **`DeepTrace_FYP_Proposal.pdf`**: Pre-compiled PDF of the FYP project proposal.
* **`uog_logo.png`**: Department/University logo asset referenced directly within `DeepTrace_FYP_Proposal.tex`.

## Compilation

To recompile the proposal from source:
```bash
pdflatex DeepTrace_FYP_Proposal.tex
```
*(Ensure `uog_logo.png` remains in this directory for relative image resolution)*.
