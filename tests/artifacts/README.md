# Test Artifacts

This directory stores generated and diagnostic test artifacts (e.g. ad-hoc ReportLab outputs, sample PDFs) used during manual or automated verification.

## Preserved Artifacts

* **`test.pdf`**: Minimal 1-page ad-hoc ReportLab test document.
* **`test_output.pdf`**: Multi-page diagnostic test document.
* **`test_num.pdf`**: Ad-hoc font and numeric character rendering test document.
